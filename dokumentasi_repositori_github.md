## ✨ Fitur Utama Website

1. **Visual 3D Interaktif (`Three.js`)**
   - Latar belakang partikel 3D dan geometri *wireframe* (*Icosahedron* & *Octahedron*) yang merespons pergerakan kursor/sentuhan secara *real-time*.
   - Efek **3D Perspective Tilt & Glare** pada kartu profil utama, galeri GSA, dan kartu proyek.

2. **Dual-Photo Switcher (`#TeamGoogle`)**
   - Pengalih tampilan foto interaktif antara **Foto Dinding 3D Google Office** dan **Poster Resmi Google Student Ambassador (`GSAID26B21662`)**.
   - Mendukung pratinjau unggah foto lokal langsung dari browser.

3. **Simulasi Aplikasi Inklusi Kampus (`UMG AccessHub v2.6 Beta`)**
   - **Transkripsi Kelas Real-Time:** Simulasi pengubah suara dosen menjadi teks visual di ruang kelas Teknik Informatika UMG lengkap dengan penyorotan istilah koding.
   - **Kamus Visual Bisindo Kampus:** Panduan gerakan tangan Bahasa Isyarat Indonesia untuk komunikasi sehari-hari di kampus.
   - **Bel Visual Kampus (*Deaf-Safe Visual Alert*):** Sistem notifikasi kilat visual pengganti pengumuman suara/audio.

4. **Dark Mode & Light Mode (`localStorage`)**
   - Desain *Glassmorphism* modern dengan penyimpanan preferensi tema otomatis yang tersinkronisasi dengan warna partikel 3D.

5. **Bilingual Instant Toggle (`ID` / `EN`) & Widget Aksesibilitas**
   - Terjemahan instan Bahasa Indonesia & Bahasa Inggris tanpa *reload* halaman.
   - Dilengkapi pengaturan perbesar/perkecil ukuran teks, font ramah baca (*Atkinson Hyperlegible*), mode kontras tinggi, dan tombol jeda animasi 3D.

## 🚀 Cara Deploy ke GitHub Pages

1. Buat repositori baru di GitHub (contoh: `portfolio` atau `username.github.io`).
2. Unggah file `index.html`, `README.md`, dan kedua file foto kamu ke repositori tersebut.
3. Buka menu **Settings** ➡️ **Pages** di repositori GitHub kamu.
4. Pada bagian **Build and deployment (Branch)**, pilih branch **`main`** dan folder **`/ (root)`**, lalu klik **Save**.
5. Tunggu 1–2 menit, dan website portofolio 3D kamu siap diakses publik!
